# @livevariant/core

The shared foundation of [LiveVariant](https://livevariant.com), an
account-free A/B testing service: URL-encoded test configs with hash
identity, stats secrets, seeded RNG, one joint linear Thompson sampling
model for every test (single-slot, contextual and multi-slot alike) with
capped warm-start priors, and event-sourced state derivation. Pure
functions, no I/O, runs anywhere.

Part of [livevariant/livevariant](https://github.com/livevariant/livevariant);
the repository README covers the whole system. AGPL-3.0.
