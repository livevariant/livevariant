# @livevariant/core

The shared foundation of [LiveVariant](https://livevariant.com), an
account-free A/B testing service driven by multi-armed bandits: URL-encoded
test configs with hash identity, stats secrets, seeded RNG, Thompson
sampling (plain, bucketed, linear) with capped warm-start priors, and
event-sourced state derivation. Pure functions, no I/O, runs anywhere.

Part of [livevariant/livevariant](https://github.com/livevariant/livevariant);
the repository README covers the whole system. AGPL-3.0.
