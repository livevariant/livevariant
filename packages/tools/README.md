# @livevariant/tools

[LiveVariant](https://livevariant.com)'s tool registry: one definition per
operation an assistant can perform (build a test, inspect one, read
results with real win probabilities), from which the MCP server, the REST
API, the OpenAPI document and the agent SKILL are all generated. Embed it
to expose the same tools from your own product without inheriting a
transport.

Part of [livevariant/livevariant](https://github.com/livevariant/livevariant);
the repository README covers the whole system. AGPL-3.0.
